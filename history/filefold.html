File and Folder is a comprehensive file management software for a small business which is sick and tired of seeing it's workers putting documents a bit everywhere in the system. File & Folder limits the users to directory structure with subroots behind, where anybody can create folders, in which documents are contained. File & Folder has been oriented Microsoft Word for Windows because of the original need of the FF client, still, future versions will support any kind of documents. File & Folder removes the ambigous concept of directories and documents and allows to manage files without any need to use Microsoft Word commands.

File & Folder is being successfully used by a small business company of about 20 workstations. Time gain has been estimated at over 80%. Documents are well organized and tracking errors has never been so easy.
